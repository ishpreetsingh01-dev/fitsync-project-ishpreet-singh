# FitSync - Health Analytics Platform 🚀

*A cutting-edge personal health analytics dashboard to visualize your fitness journey.*

## Project Overview
FitSync is a dynamic 3-page dashboard application designed to transform your personal health data into actionable insights. Built with the power of Python and Streamlit, this platform provides an intuitive interface for monitoring key performance indicators and visualizing trends in your health metrics. The dashboard comprises three main pages: Main, Dashboard (featuring KPIs and various interactive charts), and Trends (offering histograms and deep insights). Ideal for anyone looking to enhance their fitness understanding with the help of state-of-the-art data visualization techniques.

## How to Run
Follow these steps to get the project running in your environment:

1. **Clone the repository:**
```bash
   git clone <https://github.com/Saras-AI-Institute/fitsync-project-ishpreet-singh.git>
```
2. **Open in GitHub Codespaces:**
Navigate to the cloned repository on GitHub, click the <> Code button, and select Create codespace on main (or open an existing one).

3. **Run the application:**
Once the Codespace environment is ready, execute the following command in the terminal:

```bash
streamlit run main.py
```
